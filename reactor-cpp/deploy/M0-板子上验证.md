# 板子上快速验证（原 M0，已更新到全部模块）

最早的 M0 只验证「能显示一个 LVGL 页面、能读一个串口模块」。现在后台（设备层、控制核心、程序、存储、接口）和触屏都已完成，
完整的现场步骤在 **[板子联调指南.md](板子联调指南.md)**。这一页是其中**不碰硬件输出**的最短路径，大约 30 分钟，用来先确认
「能编、单测全过、界面正常、四个串口模块读得到」。

板子：Ubuntu 20.04.6 aarch64，用户 teamhd。

## 1. 编译

二选一：
- Windows + VS2022 远程编译：见 [VS2022-编译说明.md](VS2022-编译说明.md)；
- 板子上直接编：

  ```bash
  sudo apt install -y build-essential cmake pkg-config rsync libsdl2-dev libfreetype6-dev psmisc
  cd ~/reactor-cpp
  cmake -S . -B build -DREACTOR_HMI_BACKEND=SDL -DREACTOR_FULLSCREEN=ON -DREACTOR_USE_FREETYPE=ON
  cmake --build build -j4
  B=~/reactor-cpp/build
  ```

## 2. 单测

```bash
$B/run_tests
```

最后一行应是 `N 个用例，0 个失败，0 处断言失败`。（旧的 `test_modbus` 已并进 `run_tests`。）

## 3. 安装（不启动任何服务）

```bash
cd ~/reactor-cpp/deploy && sudo ./install.sh "$B"
```

## 4. 模拟模式看界面（不碰串口，旧程序可以照常跑着）

在板子桌面上开终端（ssh 进来的先 `export DISPLAY=:0`）：

```bash
mkdir -p ~/reactor-sim && cd ~/reactor-sim
/opt/reactor/bin/reactord --sim > reactord-sim.log 2>&1 &
sleep 2
/opt/reactor/bin/reactor-hmi --server unix:$HOME/reactor-sim/reactord-run/hmi.sock
```

检查：全屏（桌面分辨率，这块屏是 1920×1080，界面按 1.5 倍画）无边框、不被桌面面板挡；中文是简体字形不是方框；触摸跟手、不偏；屏幕键盘能弹出；各页面能打开；
「全部停止」会先弹确认框。退出：`Ctrl+C`，再 `pkill -f 'reactord --sim'`。

## 5. 读四个串口模块（只读）

**先停旧程序**（两个程序不能同时用一条 RS485）。停之前在旧界面上确认**没有实验在跑**——旧程序退出时会停加热、关阀、停搅拌：

```bash
sudo systemctl stop reactor-hmi
P=/opt/reactor/bin/rtu-probe
$P --preset temp  --repeat 3     # 温控 /dev/ttyS5 19200，8 路 PV
$P --preset press --repeat 3     # 压力 /dev/ttyS6 9600，8 路原码 + psi / MPa
$P --preset stir  --repeat 3     # 搅拌 /dev/ttyS4 38400，状态字
```

某个模块「没有回包」时换波特率再试（例如 `--preset temp --baud 9600`），记下实际通的波特率；和 `/etc/reactord/hardware.json`
不一致就改那里。阀门 IO16R 用的是功能码 1，`rtu-probe` 读不了，切换后由 reactord 开机读回阀态来核对（联调指南 §7）。

读完恢复旧程序：

```bash
sudo systemctl start reactor-hmi
```
