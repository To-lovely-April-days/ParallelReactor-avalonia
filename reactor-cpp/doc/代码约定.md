# 代码约定（所有模块共用）

设计见 `设计文档.md`；现有 C# 系统的事实见 `附录-现有系统盘点.md`。C# 源码在
`/Users/huanhuanremote/Desktop/Project/八通道/ParallelReactor-avalonia-fusion`（只读参考，不要改）。

## 语言和依赖
- C++17，GCC 9.4（板子）和 Apple clang（开发机）都要能编。不用 C++20 特性。
- 依赖只有：标准库、POSIX（termios / poll / socket / pthread）、`third_party/nlohmann/json.hpp`（`#include "nlohmann/json.hpp"`）、LVGL（只在 `apps/reactor-hmi`）。**不引入 Boost、spdlog、gtest 等任何新库。**
- 不用异常做正常流程控制；可失败的函数返回 `bool` / `std::optional` / 带错误码的结果结构。解析外部输入（JSON、文件）时可以 try/catch nlohmann 的异常，在模块边界内转换成错误结果。

## 目录和命名空间
| 目录 | 命名空间 | 内容 |
|---|---|---|
| `src/common/` | `reactor` | 日志 `log.hpp`（LOGI/LOGW/LOGE）、时间 `clock.hpp` |
| `src/core/` | `reactor::core` | 纯逻辑：不碰 I/O、不读时钟、不开线程；「现在」由调用方传入 |
| `src/hw/` | `reactor::hw` | 串口、Modbus 主站、总线线程、4 个设备驱动、模拟硬件 |
| `src/store/` | `reactor::store` | 设置（settings.json）、事件存储、遥测 CSV、会话、泄漏结果、程序库、硬件配置 |
| `src/net/` | `reactor::net` | 通用 HTTP/1.1 + WebSocket 服务器（TCP + Unix socket）、鉴权、CIDR、限流、幂等表 |
| `src/ctl/` | `reactor::ctl` | 控制线程、通道状态、联锁、程序引擎（后做） |
| `src/cmd/` | `reactor::cmd` | 命令层、仲裁、租约（后做） |
| `src/api/` | `reactor::api` | 端点、DTO、WS 推送（后做） |

文件名小写下划线：`over_temp_guard.hpp/.cpp`。类名 `PascalCase`，函数和变量 `snake_case`，常量 `kName` 或全大写宏都行，同一模块内统一。

## 单位和数值
- 压力内部一律 **psi（表压）**，和 C# 一样；温度 °C；时间间隔用毫秒 `int64_t`；墙上时间用 UNIX 毫秒 `int64_t`（`wall_ms()`）。
- 和 C# 对照时，常量、默认值、范围、阈值**逐个照抄**，在注释里写出处（`// C#: Models/OverTempGuard.cs`）。
- 给人看的文案（错误信息、事件标题）照抄 C# 里的中文原文。

## 测试
- 测试放 `tests/<模块>/test_*.cpp`，用 `tests/testing.hpp`：`TEST(组, 名) { CHECK(..); CHECK_EQ(a,b); CHECK_NEAR(a,b,eps); }`。
- C# 的 `tests/ParallelReactor.Tests` 里有对应用例的，**把用例逐条翻译过来**（输入、期望输出照抄）。
- 编译和运行：`make -C tools/build -j8 test`（自动收集新文件，不用改 Makefile）。提交工作前必须全绿、无编译警告。

## 线程
- `core/` 里的东西都不是线程安全的，由调用方（控制线程）保证只在一个线程用。
- `hw/` 的总线线程、`net/` 的服务器线程、`store/` 的写盘线程是各自模块内部的事，对外接口要写清楚「哪个线程可以调」。

- 不要改别的模块目录里的文件，不要改 `tools/build/Makefile`、`CMakeLists.txt`、`config/`。需要别的模块提供东西时，在自己的报告里写清楚。
- 不要提交 git，不要动 C# 仓库。
